# Regional Growth Analysis – Task 30

## 📌 Objective
Compare regional growth rates over time and practice period-over-period analysis.

## 🛠️ Tools
- SQL
- Excel
- Python (dataset preparation)

## 📊 Analysis
- Annual sales by region
- Year-over-Year growth
- Regional performance comparison
- CAGR analysis
- Regional sales trend visualization
- Small-base effect analysis

## 📁 Files
- `superstore_regional_growth_data.csv`
- `regional_growth_table.csv`

- `Regional_Growth_Analysis_Task30_Report.pdf`

## 💡 Key Learning
Growth percentages should always be evaluated together with the underlying sales base because a small starting base can make growth appear unusually high.
